* example problem specific parameter file:

ndim=2                               ; nr of paramters to optimize
varnames={x1opt}_{x2opt}             ; parameternames ( defined in .asc file ) concatenated with underscore  "_"
                                     ; The corresponding defining lines in the .asc file are
                                     ; .params x1opt=0.5 x2opt=2 for the initial starting values
                                     ; and the lines:
                                     ; .params x1={x1opt}
                                     ; .params x2={x2opt}
                                     ; The objective function is now defined in Terms of x1,x2 like
                                     ; bf f 0 v=({x1}-1)**2+({x2}-1)**2 and the corresponding .meas statement is 
                                     ; .meas op cost find v(f) at v(ref)									 
itermax=100                          ; max iterations if no convergence break before for simplex 50-200*ndim
lolimits=-1 -1                       ; lower limits for the two parameters
uplimits=5 5                         ; upper limits for the two parameters
initvals=0 0                         ; initial values of the two parameters
randominit=0                         ; if 1 the initial simplex point is choosen randomly no matter which value initvals has!!
delt=2                               ; >=2, inital simplex size (2 means - half the size of the whole parameterrange = (uplim-lolim)/2 )
                                     ; if no delt is given it is randomized between 2 and 12

* to deal with spice files

funcfile=analytic_function_2dim.log   ; where to get the actual costfunction value cost=val  computed by .meas(ure) command
ascfile=analytic_function_2dim.asc    ; the ltspice schematic file 
cirfile=analytic_function_2dim.net    ; the netlist file generated by ltspice
* cmd line without cirfilename !
spicecmdline=scad3 -b                 ; to load the simulator in batch mode : HINT: for LTSpiceXVII change it to XVIIx64.exe -b  
simendfile=tinyperl simend_ltspice.pl ; to load the simulator in graphics mode at end of optimization
ftol1=1e-7                            ; if((worstfuncval-bestfuncval)/bestfuncval<$ftol1) -> the optimization stops before itermax is reached
ftol=1e-4                             ; meanvalue of last ten funcvals=fmean if fmean-bestfuncval/bestfuncval<$ftol -> the optimization stops before itermax is reached
method=1                              ; at this stage only simplex optimization present 

* if the following line is present no spice simulation is done 
* instead the following objective function is evaluated
* NOTE: This is much faster then a spice simulation
* funcfile, ascfile, cirfile is ignored   
* Example: Rosenbrock function:
* NOTE ** is the powerfunction in perl not ^ !!!!
testfunc="(100*({x1opt}**2-{x2opt})**2+(1-{x1opt})**2)"

IMPORTANT:

For the objective function to be minimized there must always be a measurement statement in the .asc file
with must contain ONE .measure line with the name "cost"

Eg:

a multiline statement from bp_filt.asc example:
.MEASURE AC int2 INTEG V(out2)
.MEASURE AC diff12 INTEG V(out1,out2)
.MEASURE AC diff21 INTEG V(out2,out1)
.MEASURE AC cost INTEG V(out21)

or:

a oneline example statement from analytic_function_2dim.asc

bf f 0 v=({x1}-1)**2+({x2}-1)**2
.meas op cost find v(f) at v(_ref)

or:

a oneline example statement from Transformer_phase_regulation:

ev7 f 0 VALUE={IDT((v(p1))**2)} tripdv=1 tripdt=1
.meas TRAN cost FIND v(f) AT 9.99ms

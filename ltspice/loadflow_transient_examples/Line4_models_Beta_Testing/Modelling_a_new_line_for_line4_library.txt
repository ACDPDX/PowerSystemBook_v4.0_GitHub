Line4.lib is a lib file to model (transposed) distributed models for 3 and 6 phases (or more) with and without additional external earth wire
The geometrical data for the overhead line is modelled via ATP 
The capacitance and impedance matrices are copied (via verify command with pi-model)
and are the input to the appropriate excel files (for 3,4,6,7 phases)

Choose the excel file with the count of phases you need

There the matrices are converted to a format as input to matlab. 
The matrices can be fully transposed or ATP like untransposed
 


Example to model a line with 6phases+Earthwire 
Open in atpdraw the file stalu_u110_o185_2sys_coupled.acp
Double click on the LCC line symbol
Choose Pi model and press Run ATP
In the cmd box copy the Capacitance matrix for the system of physical conductors

For a transposed line model:

Paste it into the excel file stalu_u110_o185mm2_transposed_distributed_coupled_line2_2_line4_4phases_2systems.xlsx
mark the left matrix (capacitance) above before  
Pasting:
Data ? From Text/CSV ? Fixed width ? Next ? Add break lines ? Finish
Now Copy the impedance matrix for the system of physical conductors in the command box and
Paste it in the left matrix below
Data ? From Text/CSV ? Fixed width ? Next ? Add break lines ? Finish
Now you can copy/Paste the three colorful transposed matrices Cs_Cm,Ls_Lm and Rs_Rm into the matlab file
stalu_u110_o185mm2_transposed_distributed_coupled_line2_2_line4_4phases_2systems.m
to the R,L,C matrices. Then you run the matlab script and copy/paste the output into the appropriate section
in new line model in line4.lib (You have to copy/paste a already present model in line4.lib before and rename it ) DONE!

For a untransposed line model:
Open ATP_2_Matlab.xlsx
Copy past like above, Same procedure like above. 
You can paste 3 till 6+1 matrices

For a fully transposed line from with data originated from line2.lib and additional guess of system coupling and earthwire configuration 
for 6wire system or 6wire with earth system or three wire with earth system you can 
Open Matlab_input_for_Line2_2_Line_4_models_guessed_values.xlsx
Input from line2.lib file L0,L1,C0,C1,R0,R1 of a present model
Now you can model a 3lines,6lines,6lines with earthwire or 3lines with earthwire system
If you want you can change the percentage of the coupling and the Grounding (Earthwire)
Copy/Paste colored matrices 3 or,4,6,7 phases to matlab file like above

Note: If you dont have matlab you can use the online octave environement for free!!
